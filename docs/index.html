Scrobbler для Last.fm

Добавляет скробблы в профиль Last.fm: треки, альбомы и плейлисты из каталога Spotify, с выбором даты и времени. Версия сайта 1.1.1. Ключи хранятся только в этом браузере.

Настройки

Last.fm (ключи: last.fm/api/account/create)


Spotify (ключи: developer.spotify.com/dashboard)

Вход в Spotify для плейлистов (альбомы и треки работают без него). Spotify отдаёт только ваши и совместные плейлисты. Один раз добавьте этот адрес в Redirect URIs вашего приложения на сайте Spotify:
