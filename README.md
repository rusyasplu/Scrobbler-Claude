# Scrobbler — Android-приложение для Last.fm (дизайн liquid glass)

Добавляет скробблы в ваш профиль Last.fm через официальный API. Треки, **альбомы и плейлисты** ищутся в каталоге Spotify,
дата и время начала задаются вручную. Интерфейс: стеклянные карточки с размытием фона, блики по кромке,
плавающая панель вкладок «Поиск / Очередь / Профиль».

Внутри: Kotlin-оболочка с WebView (`MainActivity.kt`) и сам интерфейс на HTML/CSS/JS в `app/src/main/assets/www`.
Внешних библиотек нет.

## Как получить APK

### Вариант A. GitHub Actions (ничего не нужно устанавливать)

1. Создайте на github.com пустой репозиторий (можно приватный).
2. Загрузите в него **всё содержимое этой папки**, включая скрытую папку `.github`
   (Add file → Upload files; на macOS скрытые папки показываются по Cmd+Shift+.).
   Или через git:
   ```
   git init -b main && git add . && git commit -m "Scrobbler"
   git remote add origin https://github.com/<вы>/<репозиторий>.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** → **Build APK**. Сборка стартует сама после загрузки, либо нажмите **Run workflow**.
4. Через 4–6 минут откройте завершённый запуск и скачайте артефакт **Scrobbler-APK** (внутри `app-debug.apk`).

### Вариант B. Android Studio
Откройте папку как проект → дождитесь синхронизации Gradle → **Build → Build APK(s)**.
Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант C. Командная строка
Нужны JDK 17 и Android SDK (платформа 34): `./gradlew assembleDebug`.

## Установка на телефон
Скопируйте `app-debug.apk` на телефон и откройте. Android попросит разрешить установку из этого источника.
APK подписан отладочным ключом `app/debug.keystore`, который лежит в репозитории: так каждая новая сборка
ставится поверх предыдущей без удаления. Для личного использования этого достаточно; ключ публичный,
поэтому ставьте только APK, собранные вами в своём репозитории.

**Обновление с версии 1.0.** Версия 1.0 была подписана случайным ключом, поэтому один раз её нужно удалить
(настройки, ключи и очередь при этом сбросятся) и поставить 1.1. Дальше обновления ставятся поверх.

## Первый запуск
1. **Last.fm:** ключи на https://www.last.fm/api/account/create (API key и Shared secret).
2. **Spotify:** ключи на https://developer.spotify.com/dashboard (Client ID и Client Secret).
   С февраля 2026 владелец приложения в Development Mode должен иметь Spotify Premium,
   а поиск отдаёт максимум 10 результатов за запрос (кнопка «Ещё 10» подгружает следующие).
3. Вкладка **Профиль**: вставьте ключи, нажмите «Войти в Last.fm», разрешите доступ на сайте,
   вернитесь в приложение и нажмите «Я разрешил доступ — завершить вход».
   Пароль приложение не видит. Ключи и сессия хранятся только на телефоне.
4. **Поиск** → найти трек, артиста, альбом или плейлист → «+» → **Очередь** → дата и время → «Отправить в Last.fm».

## Альбомы и плейлисты (версия 1.1)
- Вкладка **Альбом**: найдите альбом (или вставьте ссылку `open.spotify.com/album/…`) и нажмите «+». Весь альбом
  попадёт в очередь треками по порядку; счётчик «Сколько раз целиком» повторяет альбом от первого трека до последнего.
- Вкладка **Плейлист** показывает ваши плейлисты. Чтобы их читать, нужен вход в Spotify (раздел «Профиль → Spotify: плейлисты»).
  С февраля 2026 Spotify отдаёт содержимое только **ваших собственных и совместных** плейлистов; чужие и редакторские не читаются.
  Подкасты и недоступные треки пропускаются.
- Одноразовая настройка входа: на https://developer.spotify.com/dashboard откройте своё приложение → Settings →
  **Redirect URIs** → добавьте `scrobbler://callback` → Save. Затем в приложении «Войти в Spotify»: откроется
  браузер, после разрешения Spotify вернёт вас в приложение сам. Пароль приложение не видит (вход по PKCE, секрет не нужен).
- Во всех режимах можно вставить ссылку Spotify на трек, альбом или плейлист в строку поиска.

## Сайт (папка `docs`)
Та же логика без оформления: треки, артисты, альбомы, плейлисты, дата и время, отправка в Last.fm.
Работает целиком в браузере, ключи хранятся только в нём. Публикуется через GitHub Pages:
Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/docs` → Save.
Адрес будет `https://<ваш-логин>.github.io/<репозиторий>/`.

- Для плейлистов добавьте адрес сайта (он показан в настройках на самой странице) в Redirect URIs приложения Spotify.
- Браузер ходит в Last.fm и Spotify напрямую. Если сервис не разрешает такие запросы (CORS), страница покажет ошибку
  «браузер не смог выполнить запрос»: тогда пользуйтесь приложением.
- `docs/core.js` это копия `app/src/main/assets/www/core.js`; после правки ядра скопируйте файл (тест это проверяет).

## Правила Last.fm, которые учитывает приложение
- до 50 скробблов за один запрос, дальше приложение шлёт пакетами;
- слишком старые (старше ~2 недель), слишком новые (из будущего) и сверх дневного лимита скробблы отклоняются,
  приложение предупреждает заранее и показывает причины отказа в журнале;
- треки короче 30 секунд не засчитываются, для расчёта времени такие округляются до 30 с;
- кнопка «Закончить сейчас» подбирает старт так, чтобы очередь закончилась к текущему моменту;
- «Пробный запуск» показывает план без отправки.

Last.fm может счесть искусственные скробблы нарушением правил сервиса: для основного аккаунта это риск.

## Тесты логики
`node tests/test-core.js`: подпись запросов, расчёт времени, разбивка на пакеты, альбомы и плейлисты в очереди,
вход в Spotify (PKCE, обновление токена), обработка ошибок Last.fm и Spotify на имитации серверов. Нужен Node 18+.

## Структура
```
app/src/main/java/app/scrobbler/MainActivity.kt   оболочка WebView и мост (HTTP, MD5, SHA-256, ссылки, возврат из Spotify)
app/src/main/assets/www/core.js                   логика: подпись, план, пакеты, Spotify (поиск, альбомы, плейлисты, вход PKCE)
app/debug.keystore                                постоянный отладочный ключ подписи
app/src/main/assets/www/app.js                    интерфейс и состояние
app/src/main/assets/www/style.css                 liquid glass
docs/                                             сайт: index.html, site.js, hash.js (MD5/SHA-256), core.js (копия)
.github/workflows/build-apk.yml                   облачная сборка APK
```
